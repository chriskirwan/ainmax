## [0.1.0] - 2026-11-17

Initial public release of ainmax.

### Added

- Named-array representation with explicit axis metadata.
- JAX and Equinox integration.
- Named array construction and manipulation utilities.
- Named linear algebra operations.
- Tensor contraction and einops-inspired operations.
- Support for JAX transformations and PyTree-compatible data structures.

### Notes

- This is an initial release; the public API is subject to change.
- Compatibility and functionality are documented in the project README and documentation.
